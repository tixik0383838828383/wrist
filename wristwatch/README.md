# WristWatch (Fabric 1.21.1)

Мод показывает хотбар как плавающую панель. Нажми клавишу — у тебя самого
появляется панель по центру экрана чуть ниже прицела (как плавающее окно в
VR-очках), а другие игроки с этим модом видят панель с твоим хотбаром прямо
перед твоим лицом. Никакой анимации руки — просто плавное появление/исчезание.

## Установка / сборка

1. Загрузи содержимое этой папки в подпапку `wristwatch/` в своём репозитории
   (как обычно, через веб-интерфейс GitHub).
2. Убедись, что `.github/workflows/build.yml` лежит в корне репозитория (не
   внутри `wristwatch/`).
3. Запусти сборку через Actions → Run workflow.
4. Готовый `.jar` появится в артефактах сборки.

## Настройка в игре

Две клавиши по умолчанию НЕ забинжены — назначь их в Настройки → Управление → WristWatch:

- **Check wrist watch** — включить/выключить часы
- **Open WristWatch settings** — открыть экран настроек мода

В экране настроек:

- **Обычный хотбар: показан/скрыт** — переключатель, скрывающий стандартный
  хотбар внизу экрана (раз теперь есть своя панель, дублировать его не обязательно)
- Смещение панели (для других игроков) перед лицом — вбок, вверх/вниз, расстояние
- Масштаб панели у других игроков
- Скорость появления, время удержания

Всё применяется сразу и сохраняется в `config/wristwatch.json` при выходе из экрана.

## Как это выглядит

- **У себя** — панель по центру экрана чуть ниже прицела (2D HUD, не мешает обзору).
- **У других игроков** — небольшая 3D-панель перед твоим лицом, следует за
  поворотом головы. Крепится к голове (а не к руке/кисти), т.к. голова
  гораздо надёжнее совпадает у разных моделей персонажа (в т.ч. Figura).

## Про Figura / Stick Figures

Голова в **ванильном** скелете (`PlayerEntityModel`) всегда на своём месте —
панель крепится именно к ней. У Figura нет публичного API, чтобы стороннему
моду в реальном времени видеть кости именно кастомной модели — поэтому если
Figura полностью заменяет рендер своими Lua-скриптами (как в случае со
стикменом), сама Figura-модель может визуально не на 100% совпадать с тем,
куда мод ставит панель. Обычно расхождение небольшое (голова — самая
стабильная часть скелета), и его легко подправить смещениями в настройках.

## Структура

- `WristWatchMod` — общая точка входа: сеть + серверное хранение состояния "у кого включены часы"
- `WristWatchClient` — клавиши, тик, приём сети, регистрация HUD-оверлея
- `ClientWatchState` — у кого активны часы + сглаженный прогресс появления/исчезания на клиенте
- `WatchConfigScreen` — экран настроек мода
- `WatchHudOverlay` — плавающая 2D-панель у себя (по центру экрана, ниже прицела)
- `PlayerEntityRendererMixin` + `LivingEntityRendererAccessor` — добавляют `WatchFeatureRenderer`
  к рендереру игрока без сторонних API регистрации фич-рендереров
- `WatchFeatureRenderer` — 3D-панель перед лицом, которую видят другие игроки
- `InGameHudMixin` — умеет скрывать стандартный хотбар (настройка "Обычный хотбар: скрыт")
