# WristWatch (Fabric 1.21.1)

Мод показывает хотбар в виде "часов" на руке. Подними руку (клавишей) — рука
плавно поднимается и рядом с ней появляется циферблат с содержимым хотбара
и подсветкой выбранного слота. Работает в мультиплеере: анимацию и циферблат
видят все игроки, у которых установлен этот мод.

## Установка / сборка

1. Загрузи содержимое этой папки в подпапку `wristwatch/` в своём репозитории
   (как обычно, через веб-интерфейс GitHub).
2. Убедись, что `.github/workflows/build.yml` лежит в корне репозитория (не
   внутри `wristwatch/`).
3. Запусти сборку через Actions → Run workflow.
4. Готовый `.jar` появится в артефактах сборки.

## Настройка в игре

Клавиша "поднять руку с часами" по умолчанию НЕ забинжена — назначь её в
Настройки → Управление → WristWatch.

Дальше всё настраивается командами прямо в игре, без пересборки мода:

- `/wristwatch arm left` / `/wristwatch arm right` — на какой руке рисовать часы
- `/wristwatch offset <x> <y> <z>` — сдвиг циферблата относительно руки (в блоках)
- `/wristwatch scale <значение>` — размер циферблата
- `/wristwatch pose <pitch> <yaw> <roll>` — целевой угол поднятой руки в градусах
- `/wristwatch duration <секунды>` — сколько держится поднятая рука

Настройки сохраняются в `config/wristwatch.json`.

## Про Figura / Stick Figures

Позиция руки и её поворот берутся из **ванильной** модели скелета игрока
(`PlayerEntityModel`). У Figura нет публичного API, чтобы стороннему моду
цепляться за кости конкретной кастомной модели в реальном времени — поэтому
если поверх ванильной модели рендерится Figura-аватар (например, Stick
Figures), совпадение по позиции будет достаточно точным, если пропорции руки
в модели не сильно отличаются от ванильных, но идеальной привязки к
произвольной кастомной модели мод дать не может. Если после сборки часы
оказываются не там, где нужно — подгони `/wristwatch offset` и
`/wristwatch pose` на глаз, стоя перед зеркалом/другим игроком.

## Структура

- `WristWatchMod` — общая точка входа: сеть + серверное хранение состояния "у кого поднята рука"
- `WristWatchClient` — клавиша, тик, команды, приём сети
- `ClientWatchState` — у кого активны часы + сглаженный прогресс анимации на клиенте
- `PlayerEntityModelMixin` — догибает руку к позе "часов"
- `PlayerEntityRendererMixin` + `LivingEntityRendererAccessor` — добавляют `WatchFeatureRenderer`
  к рендереру игрока без сторонних API регистрации фич-рендереров
- `WatchFeatureRenderer` — рисует подложку циферблата и иконки предметов хотбара
